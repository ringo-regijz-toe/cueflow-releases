どちらを選べばよいですか

インストーラー版 おすすめ

通常はこちらを選んでください。ダウンロードした .exe を実行するとユーザー単位でインストールされ、スタートメニューから起動できます。管理者権限は不要です。

Portable版

インストールせずに使う場合の選択肢です。ZIPを書き込み可能なフォルダへすべて展開し、中の Cueflow.exe を起動します。ZIPの中から直接起動しないでください。

GitHubのReleasesページに自動で表示される「Source code」のZIPは、実行用のアプリではありません。

動作環境

  • Windows x64向けです。主にWindows 11で検証しています。
  • Microsoft Edge WebView2 Runtimeが必要です。インストーラー版は未導入の場合に自動で取得します（インターネット接続が必要）。Portable版ではMicrosoft公式サイトから入手してください。

ご利用の前に

  • 現在は先行テスト版で、正式な完成版ではありません。大切なProjectは別にバックアップしてください。
  • Windowsのコード署名がないため、SmartScreenの警告や、Smart App Controlによる実行拒否が起きる場合があります。
  • Windowsの保護機能は無効にしないでください。実行が止められた場合は、そのまま配布を案内した連絡先へご連絡ください。
